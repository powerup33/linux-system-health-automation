# Linux System Health & Automation

A Bash-based Linux system monitoring project built on Ubuntu using Windows Subsystem for Linux 2 (WSL2).

## 🎯 Project Overview

This project automates basic system health checks using a Bash script. It collects system information, reports disk and memory usage, and evaluates disk utilization against a defined warning threshold.

## ⚙️ Features

- Displays the current date and time
- Reports disk space usage
- Displays memory usage
- Warns when disk utilization reaches 80% or higher
- Reports when disk utilization is below the warning threshold
